# ميزانيتي AI

تطبيق إدارة الميزانية الأسرية بذكاء اصطناعي.

## الميزات
- تسجيل الدخل الثابت والمتغير
- تصنيفات مصروفات قابلة للتعديل مع سقف لكل تصنيف
- حلقة ميزانية متدرجة
- تنبيهات ذكية (85% من الدخل، تجاوز السقف، شذوذ 15% عن المتوسط)
- تحليل بياني (دائري + خطي)
- تصدير/استيراد مصروفات العائلة
- مستشار AI (نسخ تقرير وفتح تطبيق AI مثبت)
- عملة: جنيه مصري، لغة: عربية RTL
